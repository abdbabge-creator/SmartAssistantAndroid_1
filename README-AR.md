# زاجل - المساعد الذكي (نسخة تطوير أولية)

## المزايا الموجودة
- واجهة عربية بسيطة.
- التعرف على الكلام بالعربية عبر خدمة التعرف الصوتي المتوفرة في الهاتف.
- الرد الصوتي باستخدام Android TextToSpeech.
- أوامر تجريبية لفتح واتساب ويوتيوب والمتصفح والإعدادات والكاميرا.
- شخصية روبوت عائمة فوق التطبيقات بعد منح إذن «الظهور فوق التطبيقات الأخرى».
- تحريك الروبوت بالسحب وحركة عائمة بسيطة، والضغط عليه لفتح التطبيق.

## البناء
1. ارفع محتويات هذا المشروع إلى مستودع GitHub.
2. افتح تبويب Actions وشغّل `Build Android APK` (أو انتظر البناء بعد push).
3. نزّل artifact باسم `zajil-assistant-debug` وافتح ملف APK على هاتف أندرويد.

## ملاحظات مهمة
- هذا مشروع مصدر قابل للبناء، وليس ملف APK جاهزاً.
- هذه نسخة أولية وليست مساعداً عاماً متصلاً بنموذج ذكاء اصطناعي بعد. المحادثة المفتوحة والبحث والطقس والرسائل تحتاج خدمات وربطاً إضافياً.
- التعرف على الكلام وتحويل النص إلى صوت قد يعتمدان على خدمات النظام والإنترنت واللغات المثبتة.
- إذن الظهور فوق التطبيقات مطلوب للشخصية العائمة. يمكن إيقافها من داخل التطبيق.
- لا يقرأ التطبيق الإشعارات أو الرسائل، ولا يرسلها، ولا ينفذ نقرات تلقائية. أي ميزة من هذا النوع يجب أن تكون اختيارية وبصلاحيات واضحة وتأكيد المستخدم.
- لا تضع مفاتيح API سرية داخل تطبيق Android؛ يمكن استخراجها من APK. ربط الذكاء الاصطناعي السحابي يحتاج خادماً وسيطاً آمناً ومفتاح خدمة.
